# Captain OSS scout — 2026-08-31

## OpenHands
- Capability: mature coding-agent platform with SDK, CLI, local GUI/API, agent server, evaluation tooling and extension ecosystem.
- License: core OpenHands and agent-server are MIT; enterprise directory has a separate commercial/source-available license.
- Maintenance: active project with 100+ releases; current public repo activity remains substantial in 2026.
- Integration fit: potentially valuable as an optional coding-agent backend/subsystem behind Captain, not as a second user-facing control-plane.
- Security/architecture note: only consider an adapter that preserves Captain's own chat_id + project_id + repo_scope gates, permission model, bounded execution and acceptance checks. Do not inherit a broad agent permission bucket.
- Laptop cost: likely materially heavier than the current lightweight Captain runtime, especially with Docker/browser/sandbox services; evaluate SDK/agent-server integration before full platform deployment.
- Decision: promising, but pending local resource/security evaluation. Do not install blindly.

## MCP Apps / official MCP Registry
- Capability: MCP Apps is an official MCP extension for interactive tool-returned UI; the official MCP Registry is a standard discovery source for MCP servers.
- Integration fit: strong candidate for future optional plugin/UI adapters while keeping Captain Settings as the canonical enable/connect/permission surface.
- Security note: registry discovery must never imply trust or auto-install. Require allowlisting, license/source review, explicit permissions and connector health checks before activation.
- Laptop cost: protocol/client support can be lightweight compared with embedding whole agent platforms.
- Decision: prioritize a small compatibility audit after current reconciliation work; do not add another router/daemon.

## Browser-use
- Capability: MIT-licensed browser-agent library; can reuse real browser profiles and supports local models/providers.
- Risk/cost: Chromium is memory-heavy and parallel agents can be expensive on a laptop. Authentication/session handling needs especially strict permission boundaries.
- Decision: useful future optional browser adapter, lower priority than reconciliation and project isolation. Never use stealth/CAPTCHA bypass as a default Captain capability.
